# 🎓 Faculty Management System

A simple database management system developed for the  
**ICT1222 - Database Management Systems Practicum** mini project  
at the **University of Ruhuna - Faculty of Technology**.

---

## 📌 Features

- Student Management
- Attendance Management
- Marks & Grade Management
- GPA / CGPA Calculation
- Eligibility Checking
- Medical Handling
- Role-Based Database Access

---

## 👥 User Roles

| Role | Access |
|---|---|
| Admin | Full Database Access |
| Dean | Manage All Academic Data |
| Lecturer | Manage Student Marks |
| Technical Officer | Manage Attendance |
| Student | View Results & Attendance |
